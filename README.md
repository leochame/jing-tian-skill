# jing-tian

景甜视角的高价值被追逐者合法谈判与自保 Skill。

## 这是什么

这个 Skill 用来分析一种网络叙事，并把它转成现实中的自我保护与合法谈判指南：孙宇晨这类高曝光、高财富人物，如何在 X、博客、媒体和评论中被写成迷恋、追逐和消费的一方；景甜又如何被写成稀缺、难以获得、具有身份象征意义的吸引对象；当现实中遇到类似的强追逐者时，如何像一个有议价权的人一样保持边界和选择权。

核心对象不是判断“景甜是否真的割了孙宇晨”，也不是教人收割不良财富或诱导他人花钱，而是拆解：

1. **对象层**：景甜被赋予了什么角色，例如白月光、明星稀缺品、身份符号或情感奖赏。
2. **行为层**：文本明确描述了谁做了什么，例如浏览主页、接近、回应、拒绝、赠与、消费、旅行、承诺或公开发文。
3. **易感层**：孙宇晨式叙事主体的迷恋触发器，例如长期投射、身份差距、稀缺性、炫耀性消费和沉没成本。
4. **归因层**：谁说“景甜让他上头/花钱/被割”，这句话是原文、媒体概括还是网友推断。
5. **应对层**：碰到类似对象时如何延缓、核验、隔离金钱与隐私、留痕、求助和退出。
6. **合法议价层**：如何把礼物、合作、陪伴和承诺改写成透明、可核验、可退出的合法安排。

## 曾颖材料

曾颖关于“景甜看她微博”的内容单独提炼为三层：

- **可见动作**：曾颖原帖或截图实际声称出现了什么访问记录。
- **曾颖解读**：她用什么语气解释或调侃这件事。
- **网友推断**：网友据此推导了什么关系或动机。

主页访问不能单独证明见面、恋爱、交易或动机。原帖无法取得时，只写“媒体/转帖声称”。

## 使用方式

读取 [`SKILL.md`](SKILL.md) 获取完整流程，读取 [`references/source-ledger.md`](references/source-ledger.md) 获取来源账本和对象—行为字段。

每条材料至少记录：

```text
来源 → 叙事对象 → 行为主体 → 可见动作 → 解释/归因 → 迷恋触发器 → 证据状态
```

现实建议采用：

```text
识别 → 延缓 → 核验 → 隔离 → 留痕/求助 → 退出
```

## 证据边界

不把未经证实的操控、索取、欺骗、性关系或财务指控写成事实；不从“明星稀缺对象”的角色定位反推出景甜真实动机；不提供暧昧操控、制造嫉妒、放大沉没成本、套取转账、洗钱或诱导花钱的教程。现实建议优先保护人身安全、财产独立、隐私和退出权，并核验资金来源与合规性。
