# jing-tian

碰到孙宇晨式追逐者时，如何像景甜一样思考。

## 这是什么

一份行动手册，不是纠纷复盘。

对象是**一类人**：资源比你多、声量比你大、推进速度极快、习惯用第一人称长文解释世界，并且总能把自己写成深情或受害的一方。他追你、捧你、为你花钱，然后有一天这一切会变成一份账单——舆论的、法律的，或者两者都有。

Skill 只回答一个问题：

> 站在被追逐的一方，怎么做，才能让对方的钱、声量和叙事在你这里失效？

## 核心判断

他的三样武器——钱、声量、叙事——有一个共同前提：**需要你在场、需要你回应、需要你被写进去**。

所以你的筹码不是姿色、感情或谈判技巧，是**同意权**。这些他一样都买不到，只能等你给。

上位优势 = 你知道自己手里有这个开关，并且不轻易按。

## 降维打击的定义

不是压过他，是换赛道。把整场互动降到三个维度：

```text
口头、情绪、即时   →  书面
公开、围观、多回合 →  单点
感情账、人情债     →  可核验
```

结果：钱买不到书面同意，声量打不动不回应的人，叙事需要主角配合。他的武器在你选的坐标系里不生效。

## 背调：杠杆最高的一步

识别出信号之后，先查，再想怎么应对。

**前任的公开账号是最高价值信源**。他自己的长文和媒体转述都是他控制的输出；只有前任见过没有观众时的他——而资源展示、深情告白、私人飞机全部发生在有观众的场合。

由此得到 Skill 里最重要的一条推论：

> **资源展示是获取阶段的成本，不是关系存续期的标准。**

同一个人，追求期可以百万美元包酒店，存续期可以是凉拌沙拉和"美国医疗太贵"。差异不来自爱的程度，来自阶段和观众。所以有人用远超常规的排场开场时，正确反应不是"他很重视我"，而是**去查他上一段关系怎么结束的**。

查六项：退出史、困难期行为、他人投入的处理方式、诉讼与监管史、叙事习惯、资金结构。其中叙事习惯要特别看——**他怎么写上一个人，就是他将来怎么写你**。

纪律：只用公开渠道，不接触前任索要私料，不留痕，不传播，只提取模式不下人品判断。

## 八个上位动作

```text
1. 资源展示不产生对价    5. 一切转成书面
2. 强制降速              6. 钱必须有名字
3. 不进入他的时间线      7. 从第一天就设计退出
4. 不接叙事，包括不反驳  8. 退出时一次做完
```

第 3 条最关键：一旦你出现在他的公开叙事里，你就从当事人变成了他故事里的角色，而角色没有解释权。

完整招式对照表和每条动作的原理，见 [`SKILL.md`](SKILL.md)。

## 红线

Skill 里有一节专门写**哪些做法会让你当场失去优势**——收下性质不明的钱、维持暧昧延长对方投入、制造嫉妒放大沉没成本、用曝光反击、私下拿钱和解、帮忙代持走账、逐条澄清。

这些不是道德说教，是策略成本：七条的共同点都是主动走进他的坐标系，而他在那个坐标系里比你强得多。上位优势的全部内容就是不进去。

## 素材边界

景甜-孙宇晨-曾颖的公开材料仅用于提炼行为模式和演示背调方法，剥离人名和金额后使用。不判断任何人的动机或对错，不把长文、访谈、律师采访当作事实认定。

曾颖的自述一律写作"曾颖称"；访客记录只能证明"她发布了截图并如此声称"，不能证明访问真实发生、更不能证明动机。截至 2026-08-28，无任何同框照片、视频或聊天记录公开，情侣说法全部来自网友推测。

时间线、否定项、来源清单和证据分级见 [`references/source-ledger.md`](references/source-ledger.md)。
